Deep Copy and Shallow Copy :- 

shallow copy :- A shallow copy creates of an object , but nested object are copied by references , not by the value .

 This means both object share the same  nested object in memory.

 

 Deep Copy :- A deep copy create a completely indepedent copy of an object,including all nested objectes.

 changes in the copied object do not affect to original object.
