Nodejs :- 


Definition :- nodejs is a open source,cross platform , javascript 
             runtime environment built on chrome v8 javascript engine.
             It allows developer to run the javascript code on the server side , enabling the creation of scalable , high performance applicatios.


Overview of Nodejs/Featurs of Nodejs :- 
1. Single threaded - event loop :- Handles multiple request efficiently without creating new thread for each request.
2. Non-blocking I/O(Asynchronous Operation) :- Performs I/O operations asychronusly.
3. Lightweight and fast :- V8 engine , Nodejs executes JS code at high speed.
4. Open Source :- Any one can access freely.
5. cross platform :- we can run on the any system like windows , Linux , Mac.
