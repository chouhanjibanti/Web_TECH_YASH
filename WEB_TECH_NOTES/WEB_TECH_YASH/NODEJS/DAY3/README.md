Modules :- 

modules -> bundles of logic , we can reuse 

Mainly we have two type of modules :- 
1. Built in Modules :- predefined in the nodejs.
    http -> hyper text transfer protocol 
          -> server creations 

    fs  -> file system 
         -> write , read , delete , copy , mkdir 

    path  -> file path handling 

==========================================================
