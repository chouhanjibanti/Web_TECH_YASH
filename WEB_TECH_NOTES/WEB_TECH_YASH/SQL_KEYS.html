Database Concepts

SQL Keys

A complete visual reference to all 7 types of SQL Keys

Keys are sets of attributes used to uniquely identify a specific row in a table and to establish relationships between two or more tables. An Attribute is a property that defines an entity (e.g., a column in a table).
① The 7 Types of SQL Keys
KEY 01

Candidate Key (Key Attribute)

An attribute that can uniquely identify every record in a table. A table can have multiple candidate keys.

phone_nomail_id aadharPAN passportbank_ac
KEY 02

Non-Key Attribute

All attributes that cannot uniquely identify a record on their own. They describe the entity but don't serve as identifiers.

nameage genderdob
KEY 03

Primary Key (Prime Key Attribute)

The chosen candidate key selected as the main identifier for a table. Only ONE per table. Cannot be NULL.

phone_noaadhar emp_idPAN
KEY 04

Non-Prime Key Attribute

All candidate keys that were not selected as the primary key. They are still unique but act as alternates.

mail_idpassport ration_id
KEY 05

Composite Key Attribute

A combination of two or more non-key attributes that together uniquely identify a record. Used when no single key attribute exists.

name + dobcity + pincode
KEY 06

Super Key Attribute

A superset of all candidate keys. Any combination that includes a candidate key is a super key. Every candidate key is a super key, but not vice versa.

phone_noaadhar PANpassport dlbank_ac
KEY 07

Foreign Key Attribute

An attribute in one table that references the primary key of another table. Used to establish and enforce referential integrity between tables.

DNO → Dept table
