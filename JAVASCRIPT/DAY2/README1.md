Variable :- Variable is container used to store the value.

Mainly we have three types of variable :- 
1. var 
2. let 
3. const 


Diff b/w var , let and const 
1. scope of var variable is global.  
1. scope of let variable is block
1. scope of const variable is block


2. Declaration is poss in var
2. Declaration is poss in let 
2. Declaration is not poss in const.

3. Reinitilaztion is poss in var.
3. Reinitilaztion is poss in let
3. Reinitilaztion is not poss in const .

4. Redeclaration is poss in var.
4. Redeclaration is not poss in let.
4. Redeclaration is not poss in const.
