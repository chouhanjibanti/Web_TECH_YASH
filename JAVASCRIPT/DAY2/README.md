DataType :- 
1. primitive :- predefined
2. Non Primitive :- user defined 

Primitive => number , String , null , boolean , undefined , NAN
Non primitive DT :- Array , Object , Function

Array :- it is a non primitive dt. it is huge memory block used to store the diff types of elements.

Homogenous :- Same types , java  , c++ 
Heterogenous :- Diff types . javascript

Syntax :-

let arr = [1,2,3,'hy','by',true]
